# 📱 폰 온도 알림 (Heat Alarm)

안드로이드 폰의 **배터리 온도를 자동으로 읽어서**, 뜨거워지면 알림을 보내는 앱입니다. 파이썬(Kivy)으로 만들었습니다.

- 앱 화면: 지금 배터리 온도, 단계(정상·따뜻함·주의·위험), 행동 요령, 단계별 배경색
- 백그라운드 감시: 앱을 닫아도 30초마다 온도를 확인하고, 주의(40°C)·위험(45°C) 단계로 올라가면 알림 (위험이면 진동)

| 단계 | 배터리 온도 |
|---|---|
| 정상 | 35°C 미만 |
| 따뜻함 | 35°C 이상 |
| 주의 | 40°C 이상 |
| 위험 | 45°C 이상 |

충전 중에 40°C가 넘으면 "충전기를 먼저 분리하세요"를 덧붙입니다.

## 파일
- `main.py` — 앱 화면
- `heat.py` — 온도 판정 규칙
- `battery.py` — 안드로이드 배터리 정보 읽기
- `service.py` — 백그라운드 감시
- `buildozer.spec` — 안드로이드 앱(APK) 설정
- `.github/workflows/build-apk.yml` — GitHub가 APK를 자동으로 만드는 설정
- `NanumGothic-Regular.ttf` — 한글 글꼴 (SIL Open Font License, `OFL.txt`)
